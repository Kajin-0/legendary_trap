# FOCUS RoFormer evaluation

The experiment stopped at the mandatory checkpoint-license gate. The
recommended modern MelBand-RoFormer inference package is MIT, but its Kim
vocal checkpoint is explicitly `CC-BY-NC-SA-4.0`. Community alternatives in
the inspected registry are unreviewed, so no weights were downloaded and no
separation or ASR was run.

This phase therefore produced no acoustic improvement: FOCUS remains at 78/82
direct lead lines and 543/602 direct tokens. Existing htdemucs metrics remain
the only separation result and were not rerun. No audio, stem, cache, or model
weight is tracked.
