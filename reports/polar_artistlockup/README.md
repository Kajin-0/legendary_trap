# 350 Hz polar artist-lockup review

This is a visual-only refinement of the approved `trap_polar_350hz_maximpact`
direction. The cutoff remains 20–350 Hz, the polar center and impact stack are
unchanged, and only the lower-arc gain was raised from 0.18 to 0.32 so the
bottom visibly breathes without matching the upper lobes.

The font shootout includes Super Crown and the previously installed heavy
faces. Barlow Condensed Black is selected for lyric lines. Super Crown is
reserved as a possible identity/artist font because its graffiti treatment is
too decorative for long lyrics.

No authoritative artist name or repository-local PFP exists for this song, so
the preview deliberately renders no fabricated artist lockup. The lockup
configuration is present and reports missing metadata explicitly.
