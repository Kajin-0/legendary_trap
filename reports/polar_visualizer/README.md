# Polar low-mirror visualizer

This shadow/prototype visualizer uses a dedicated 20–700 Hz, 32-sample
log-spaced feature. The main polar contour discards higher frequencies;
high-frequency energy remains available for particle brightness and sparkle.

The upper arc uses one low-end profile mirrored across the vertical axis. Bass
controls the lobe displacement and whole-ring breathing, while the lower arc
remains a restrained halo. Existing sunset, particles, vignette, signed shake,
and centered Montserrat lyric rendering are retained.
