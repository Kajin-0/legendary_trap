# Structural alignment shadow evaluation

The reports in this directory are shadow-mode diagnostics generated from the
existing canonical timing artifacts. No new model inference is used. Section
occurrences are kept chronological, repeated fingerprints remain distinct, and
primary lead events are separated from ad-lib-only events.

Promotion is intentionally conservative: a candidate must improve a named
weak region without changing non-target timing. Production timing remains the
source of truth until that comparison is explicit.
