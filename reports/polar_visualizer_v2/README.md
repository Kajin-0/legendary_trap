# Polar visualizer v2

The v2 prototype keeps the 20–700 Hz low-spectrum input and excludes highs
from the main polar geometry. The full circumference now responds through a
weighted angular response: upper lobes are strongest, side arcs are moderate,
and the bottom arc remains visibly reactive but restrained.

The polar center is moved behind the centered lyric region. The three particle
depth classes use different sizes, opacity, drift speed, and short inertial
trails. Bass/transient impact is shared by polar displacement, particle speed,
vignette pressure, luminance, translation, and signed rotation. The landscape
continues drifting at separate far/near rates.
