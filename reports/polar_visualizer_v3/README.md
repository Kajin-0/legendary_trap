# Maximum-impact polar A/B

This review compares identical renders using 20–500 Hz and 20–350 Hz
log-spaced low-spectrum inputs. The same bass-focused weighting, approved
polar placement, Barlow Condensed lyric styling, particle depth field, and
impact stack are used in both videos.

High frequencies remain decorative only: they affect particle brightness and
glints, never the main polar radius. The lower arc uses the same low spectrum
with weaker angular gain, so it breathes without competing with the upper
808-driven lobes.
