# Source transport

Upload the original `Suno.zip` to this directory as:

`source/Suno.zip`

This ZIP is intentionally tracked because GitHub is the transport path to the VPS. The archive is treated as immutable source material. Runtime extraction goes to `input/audio/`, which remains untracked.

Do not edit or regenerate the authoritative lyrics from ASR. The committed files under `input/lyrics/` remain ground truth.
